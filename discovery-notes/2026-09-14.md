# askhermie.dev discovery run — 2026-09-14

## Accepted and published

- What's Up Docker? (WUD) — container update monitoring for owned Docker/Kubernetes/Nomad/Compose environments. Safety note: keep private, avoid raw socket exposure where possible, and do not enable unattended updates while learning.
- LogTide — self-hosted logs/traces/metrics platform with a lightweight Docker option. Safety note: logs and traces can include sensitive URLs, IDs, hostnames, and secrets; keep dashboards private and scrub data.
- tinysearch — Rust/Wasm static-site search engine. Safety note: inspect generated indexes before deployment because they can leak draft/private pages and internal URLs.
- MkDocs — Markdown-first documentation site generator. Safety note: review docs for hostnames, screenshots, commands, and placeholder credentials before publishing.
- docmd — Markdown documentation compiler that also emits machine-readable AI context artifacts. Safety note: inspect generated llms.txt/search indexes/knowledge bundles for private paths and secrets.

## Rejected or deferred

- PwnPad — deferred. It is an educational hardware-hacking platform, but the README and scope include exploit/attack/side-channel challenges; too dual-use for a beginner public card without deeper bounded write-up.
- CompartIoT — deferred. Hardware-security training repo has no license metadata from GitHub API and includes firmware exploitation language; safety/legal framing is not strong enough for publication.
- Hearth — deferred. Interesting home-AI observability dashboard, but very low adoption signal at inspection time and alpha status; revisit after maturity.
- LabKit ESP32 firmware — deferred. Local ESP32 browser tool looks benign, but public repo has zero-star maturity signal; revisit if project gains clearer reputation/docs.
- Activepieces mirror repo at Ahrvo-Technologies/mcp_agent — rejected/deferred. It appears to mirror Activepieces content under a confusing repo identity with no stars and unclear license metadata; use the official project instead if needed.
- Lab Dash — deferred. Useful homelab dashboard, but the published install asks for privileged container mode and raw Docker socket access; too risky for beginner copy/paste publication.
- zepgram/pi-dashboard — deferred. No license metadata from GitHub API and README references secrets/API keys/Docker socket; not enough trust for publication.
- JanuScope — deferred. Potentially useful MCP policy proxy, but low adoption and many sensitive secret/credential handling surfaces; needs deeper review.
- agentic-community/mcp-gateway-registry — deferred. Stronger project signal, but enterprise auth/gateway setup is complex and credential-heavy; not a beginner card for this run.
- tool-sandbox-mcp — deferred. Interesting MCP sandbox idea, but very low adoption signal and code-execution semantics need deeper review.
