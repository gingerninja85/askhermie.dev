# askhermie.dev discovery run — 2026-09-30

## Accepted and added

- MCP Memory Service — self-hosted MCP/REST memory backend for agents. Safety: may store private prompts, code, paths, and decisions; recommend dummy data first.
- Moss — fast retrieval SDK for AI apps/RAG prototypes. Safety: retrieval indexes can contain private docs; use public samples first and review cloud key/data handling.
- maintenant — self-hosted infrastructure/container monitoring. Safety: reads Docker/Kubernetes state and its quickstart warns about UI/API exposure; bind locally and put auth in front.
- Nightbell — Android phone-based uptime monitor. Safety: only monitor owned/authorized services; URLs and alert history live on the phone.
- SonosESP — ESP32-P4 Sonos touchscreen controller. Safety: firmware flashing can brick unsupported hardware and controls real speakers; bench-test on supported panels.
- EnergyMe-Home — ESP32-S3 open hardware/software home energy monitor. Safety: mains-panel work is dangerous; use qualified help and study docs before touching hardware.

## Already present / inspected

- HOL Guard — README and metadata inspected; already present in the catalog, so not duplicated.
- Kuvasz — README and metadata inspected; already present in the catalog, so not duplicated.

## Rejected or deferred

- r0crawl_skills — rejected. Broad reverse-engineering skill arsenal includes anti-analysis, malware triage, Frida stealth/dumping, and ambiguous operational modules; not suitable for a beginner public catalog.
- gptme — deferred. Useful terminal agent, but README emphasizes unconstrained shell/browser/tool access; needs a tighter safety framing before recommending to beginners.
- Strands Agents / harness-sdk — deferred. Broad production agent SDK; useful but needs deeper review of tool/runtime permission model before adding.
- KryonOS — deferred. Interesting ESP32 JavaScript OS, but early hardware/cloud/app-store surface needs more maturity review before a beginner recommendation.
- ServiceRadar — deferred. Large network management/security analytics stack; potentially useful, but requires deeper review because it scans/monitors networks and ships many components.
