## Accepted and published

- Wokwi — accepted. Browser electronics simulator for ESP32/Pico/Arduino learning; safe when framed as simulation, with real-hardware electrical caveat.
- MQTT Explorer — accepted. Beginner-friendly MQTT topic browser for owned brokers; safety note warns about private device/topic data.
- Eclipse Mosquitto — accepted. Core MQTT broker and CLI tools for local IoT labs; safety note forbids exposing unauthenticated brokers.
- OpenCanary — accepted. Defensive honeypot for owned/private networks; safety note covers isolation and sensitive logs.
- OWASP Juice Shop — accepted. OWASP-maintained deliberately vulnerable app for legal web-security labs; safety note says local/isolated only.
- Temporal — accepted. Durable workflow engine useful for resilient automation/agent jobs; safety note covers retried side effects and idempotency.
- Homebox — accepted. Self-hosted home/lab inventory system; safety note covers valuables, serial numbers, and private exports.
- Hoppscotch — accepted. Open-source API client for local/API debugging; safety note covers tokens, cookies, and shared workspaces.
- Huginn — accepted. Self-hosted automation agents for watch/filter/notify workflows; safety note covers cookies, tokens, scraped content, and actions.
