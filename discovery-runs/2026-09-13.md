# Discovery run — 2026-09-13

## Accepted and published

- Dockge — accepted. Safe self-hosted Docker Compose stack manager; active repo, MIT license, clear Docker install docs. Safety note: private-only admin surface; back up compose files.
- Gitingest — accepted. Safe codebase-context exporter for AI/code review workflows; active repo, MIT license, standard pip/pipx install path. Safety note: output may contain private code or secrets.
- Pocket ID — accepted. Benign passkey-focused OIDC provider for homelabs; active repo, BSD-2-Clause license, documented setup. Safety note: identity provider is security-critical; test with HTTPS and recovery path.
- OliveTin — accepted. Benign predefined-command web dashboard for owned systems; active repo, AGPL-3.0 license, docs-first install. Safety note: command runner must stay authenticated and narrow.
- Kopia — accepted. Benign backup tool with encryption, snapshots, CLI/GUI; active repo, Apache-2.0 license, documented install. Safety note: verify restores and protect repository credentials.
- btop — accepted. Benign local terminal system monitor; active repo, Apache-2.0 license, package-manager installs. Safety note: screenshots can leak private process details.
- Scrutiny — accepted. Benign S.M.A.R.T. drive-health dashboard; active repo, MIT license, Docker/manual install docs. Safety note: dashboard exposes host/storage details.
- Frigate — accepted. Benign self-hosted NVR/local object detection for owned cameras; active repo, MIT license, official docs. Safety note: camera footage is sensitive and requires consent/legal care.
- Zigbee2MQTT — accepted. Benign Zigbee-to-MQTT bridge for local smart-home systems; active repo, GPL-3.0 license, adapter/device docs. Safety note: affects real devices; keep private and avoid unsafe actuators.
