# Discovery run 2026-09-23

## Scope
Daily askhermie.dev autonomous discovery loop. Inspected GitHub candidates across AI-agent/MCP tooling, observability, homelab dashboards, firmware/ESP32 tooling, and agent governance.

Metadata and README evidence was fetched directly from the GitHub API/raw README endpoints during the run. Raw README JSON was not committed to avoid publishing third-party examples or accidental secrets.

## Accepted and published

- **mcpc** (`apify/mcpc`) — accepted. Apache-2.0, active, reputable Apify project, README describes universal MCP CLI for testing MCP servers. Safety note: MCP clients can access tools/OAuth sessions; use sandbox servers and protect tokens/transcripts.
- **Context7** (`upstash/context7`) — accepted. MIT, active, widely used docs/MCP platform. Safety note: generated editor/MCP config changes agent context; review config and avoid leaking private project details.
- **OpenLIT** (`openlit/openlit`) — accepted. Apache-2.0, active OpenTelemetry-based AI observability/evals platform. Safety note: traces can contain prompts, tool outputs, costs, and user data; keep lab installs private and redact exports.
- **pktvisor** (`netboxlabs/pktvisor`) — accepted. MPL-2.0, active NetBox Labs network observability agent. Safety note: packet telemetry reveals hosts/domains/services; only capture owned/administered networks.
- **AegisFlow** (`saivedant169/AegisFlow`) — accepted. Apache-2.0, active, policy gateway for coding-agent action review. Safety note: gateway logs and evidence may expose prompts, credentials metadata, and tool requests.
- **Caura** (`caura-ai/caura`) — accepted. Apache-2.0, active shared governed memory for agent fleets. Safety note: memory stores can accumulate prompts, project facts, user data, and accidental secrets; start with fake data and enforce policies.
- **deco Studio** (`decocms/studio`) — accepted. MIT, active AI workspace/control plane. Safety note: brokered tools, OAuth credentials, prompts, billing, and logs are sensitive; use test accounts first.
- **Jira Skill** (`netresearch/jira-skill`) — accepted. Active Jira agent skill package; useful for project-management integration workflows. Safety note: Jira integrations touch private project data and credentials; use least-privilege accounts and keep env files private.
- **OpenTelemetry Agent Skills** (`ollygarden/opentelemetry-agent-skills`) — accepted. Apache-2.0, active vendor-neutral skill pack grounded in upstream OpenTelemetry sources. Safety note: installed skills affect agent behavior; review contents and avoid production telemetry secrets in examples.
